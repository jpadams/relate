= Stack Overflow — a workload grown in rounds

The expand-workload skill applied iteratively: the notebook's queries are round 0, and each round adds one capability the way a feature request would, extending queries already proven. The dataset itself grows at round 10: real comments and the related ring from the Stack Exchange API.

Grown by the expand-workload skill and validated against a store of 1081 nodes / 1347 relationships on `relate`.
